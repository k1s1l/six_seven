# Бот «67» — установка и запуск на Windows

## Что делает бот

- `/start` → меню: 🔥 67 / ⚙️ Настройки / 🛑 Стоп
- «🔥 67» → выбор количества сообщений (10 / 25 / 50 / 100)
- Бот отправляет `67` несколько раз **в тот же чат**, где его вызвали
- Максимум 100 сообщений за один запуск, кулдаун между запусками,
  мгновенная остановка кнопкой «🛑 Стоп» или командой `/stop`
- Бот **не** пишет в личные сообщения по `@username` и работает
  только в чатах, где он присутствует

---

## 1. Получить токен бота

1. Откройте Telegram, найдите **@BotFather**.
2. Отправьте команду `/newbot` и следуйте инструкциям (укажите имя и username бота).
3. BotFather пришлёт токен вида `123456789:AAExampleTokenHere`. Сохраните его —
   он понадобится на шаге 4.

---

## 2. Установить Python

1. Скачайте Python 3.12 с официального сайта: https://www.python.org/downloads/
2. При установке **обязательно** поставьте галочку **"Add python.exe to PATH"**.
3. Проверьте установку — откройте **PowerShell** или **Командную строку (cmd)** и введите:

   ```powershell
   python --version
   ```

   Должно вывести что-то вроде `Python 3.12.x`.

---

## 3. Скачать/распаковать проект

Поместите все файлы проекта в одну папку, например:

```
C:\bots\bot67\
├── bot.py
├── config.py
├── requirements.txt
├── .env.example
└── README.md
```

---

## 4. Создать файл `.env`

1. Скопируйте `.env.example` и переименуйте копию в `.env`
   (в проводнике: правый клик → Копировать, затем переименовать копию).
2. Откройте `.env` в Блокноте и вставьте свой токен:

   ```
   BOT_TOKEN=123456789:AAExampleTokenHere
   MAX_MESSAGES=100
   SEND_DELAY=0.6
   COOLDOWN_SECONDS=30
   ```

3. Сохраните файл.

> ⚠️ Убедитесь, что файл называется именно `.env`, а не `.env.txt`.
> Если Блокнот добавил `.txt`, включите отображение расширений файлов
> в проводнике (Вид → Показать → Расширения имён файлов) и переименуйте.

---

## 5. Установить зависимости

1. Откройте **PowerShell** в папке проекта:
   - зайдите в папку проекта в проводнике;
   - зажмите `Shift` + правая кнопка мыши на пустом месте папки;
   - выберите **"Открыть окно PowerShell здесь"** (или "Открыть терминал здесь").

2. (Рекомендуется) Создайте виртуальное окружение:

   ```powershell
   python -m venv venv
   venv\Scripts\activate
   ```

   После активации в начале строки появится `(venv)`.

3. Установите зависимости:

   ```powershell
   pip install -r requirements.txt
   ```

---

## 6. Запустить бота

В том же окне PowerShell (с активным `venv`, если вы его создавали):

```powershell
python bot.py
```

В консоли должно появиться:

```
... | INFO | bot67 | Бот запущен, начинаю polling...
```

Бот запущен и работает. Не закрывайте окно консоли, пока хотите,
чтобы бот оставался онлайн.

Чтобы остановить бота — нажмите `Ctrl + C` в окне консоли.

---

## 7. Добавить бота в чат и проверить

1. Добавьте вашего бота в нужную группу/чат Telegram (или напишите ему
   лично, если хотите протестировать в личном чате).
2. Если бот добавлен в группу — убедитесь, что у него есть право
   отправлять сообщения (в настройках группы → Администраторы/Участники).
3. Отправьте в чате `/start`.
4. Нажмите «🔥 67», выберите количество — бот начнёт слать `67` в этот же чат.
5. Чтобы остановить — нажмите «🛑 Стоп» или отправьте `/stop`.

## Частые проблемы

| Проблема | Решение |
|---|---|
| `BOT_TOKEN не найден` | Проверьте, что файл называется `.env` (не `.env.txt`) и лежит рядом с `bot.py` |
| `ModuleNotFoundError: No module named 'aiogram'` | Убедитесь, что виртуальное окружение активировано (`venv\Scripts\activate`) и выполните `pip install -r requirements.txt` заново |
| Бот не отвечает в группе | Проверьте, что у бота есть права писать сообщения в этой группе, и что у бота отключен Privacy Mode в @BotFather (`/setprivacy` → Disable), если хотите, чтобы он видел все сообщения |
| `python` не распознаётся как команда | При установке Python не была поставлена галочка "Add to PATH" — переустановите Python с этой галочкой |

## Настройка параметров

В файле `.env` можно менять:

- `MAX_MESSAGES` — жёсткий потолок сообщений за один запуск (по умолчанию 100)
- `SEND_DELAY` — пауза между сообщениями в секундах (по умолчанию 0.6)
- `COOLDOWN_SECONDS` — пауза между запусками в одном чате (по умолчанию 30)

После изменения `.env` перезапустите бота (`Ctrl+C`, затем снова `python bot.py`).
